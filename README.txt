时迹 TimeTrace v1.6.0
=====================

给 RustTimeNoter 装一条时间线：看清「几点几分在用什么软件」。

先决条件
--------
先装好 RustTimeNoter（本工具只读它的数据，不记录任何东西）。
如果记录器没在跑，时迹会自己把它启动起来；没有开机自启也会自动补上。

关于原作者
----------
时迹不是数据采集器。原始的使用记录由 RustTimeNoter 采集并加密存储，
本工具只读取它导出的数据、做成时间线页面；RustTimeNoter 及其版权
归原作者所有。该项目目前在网络上没有可直接引用的主页，这里以项目名致谢。

快速开始
--------
1. 把这个文件夹解压到任意位置（不用管理员权限）
2. 双击「时迹.bat」——右下角出现托盘图标，控制台窗口会自动隐藏
3. 右键托盘图标就是菜单

托盘菜单
--------
  打开时间线（所有日子、图标、U 盘）    ← 左键单击图标也是这个
  查某个时刻在用什么
  查某个软件什么时候被用过
  查 U 盘：接入 / 打开 / 下载
  某个日期的文字流水
  记录器状态与数据位置
  ─────────────
  开机自动启动（勾选）
  退出

选中的操作会弹一个小控制台窗口显示结果，关掉就回到托盘。
命令行别名（脚本里用）：
  TimeTrace.exe --tray   启动托盘
  TimeTrace.exe html / at "14:30" / app pallas / events / status

U 盘记录
--------
页面顶部会多一张「U 盘记录」卡片，分三块：

1. 接入时刻：来自 Windows 设备日志（Kernel-PnP），不需要管理员权限。
   只记时间 + 设备 ID + 盘符，没有拔出时间；从未分配盘符的设备显示「—」。
2. 打开过的文件：来自 Windows「最近使用」记录，只列 U 盘上的条目，
   例如 10-23 21:38 打开过 E:\Wired_driver_31.2.2_x64.zip。
3. 下载到 U 盘的文件：来自 Edge / Chrome 的下载记录（先复制数据库再查，不改原文件），
   能看出「电脑下好直接放进 U 盘」这个方向。

方向能看出一部分：从 U 盘打开过（②）、下载到 U 盘（③）。
看不到：资源管理器里拖拽、复制粘贴、右键发送到，两个方向 Windows 都不记录；
想知道「拷走了什么」只能事前开对象访问审核或装监控，历史补不回来。
不读文件内容、不写设备序列号。
不想读这些记录：TimeTrace.exe html --no-events

页面上的按钮
------------
- 应用都显示真实图标（从本机 exe 本地提取，不上传）；色带下面一排图标是每小时的主力应用
- 右上角「保存本页」：另存为独立的 HTML 报告（数据在文件里，自己保管）
- 「每天默认收起表格」：勾上后点日期那一行展开当天的完整会话表
- 「全部应用」：点任意应用可只看它；再点一次取消
- 输入 14:30 或 2026-10-26 14:30：直接跳到那一刻并高亮

图标说明
--------
图标只在你生成页面时读一次，缓存到 %LOCALAPPDATA%\TimeTrace\icons（每个约 1.5 KB），
之后直接复用；不新增常驻进程，也不影响 RustTimeNoter 采集。
取不到图标的程序会自动退回色块。不想用图标：TimeTrace.exe html --no-icons

保留 30 天
----------
每次运行都会先删除 30 天以前的日志分片（硬删除，不进回收站）。
只删 %LOCALAPPDATA%\RustTimeNoter\data 下形如 YYYY-MM-DD.log 的文件，
配置、密钥、字典和其它文件不动。
先看会删什么：  TimeTrace.exe prune --dry-run
想保留更久：    TimeTrace.exe prune --days 60

隐私
----
所有数据都在本机，页面是离线 HTML，不联网、不收集任何信息。
「保存本页」得到的文件包含你的完整操作记录，请自行保管。

常见问题
--------
* 提示找不到 tracker.exe：先安装 RustTimeNoter；或把 tracker.exe 放到本文件夹。
* 杀毒软件报毒：exe 由 PyInstaller 打包且未签名，可能误报。
  可以改用 Python 运行 timetrace.py，或用 build.ps1 自己重新打包。
